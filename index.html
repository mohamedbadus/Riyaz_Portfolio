TestCraft

An assessment generator for state-board classrooms

Writing a question paper by hand is a slow, fiddly job. A teacher has to hold the whole blueprint in their head — how many one-mark questions, which chapters are in scope this term, how the marks add to a hundred — and then type the thing out and format it so it prints cleanly.

TestCraft takes the blueprint as input instead. You tick the chapters you have covered, choose the paper you want, and it plans the parts, fills each slot with questions drawn from those chapters, and lays the result out ready for the photocopier. It is built for the Tamil Nadu Samacheer Kalvi Class 10 syllabus, across all five subjects, in English medium, Tamil medium or both side by side.

The interesting part is not the prompt. It is the contract around it: Gemini Flash is asked for a strict JSON object matching the blueprint the app has already decided on, so the generated paper is checked against the plan before a single line reaches the page.

Clinic Appointment & Management System

React, Node.js, Express, MongoDB

A small clinic runs on a paper diary and a phone that keeps ringing. This replaces both: patients book a slot against a doctor’s real availability, records stay with the patient rather than in a folder, and the front desk gets one dashboard for the day instead of three notebooks.

Built on an MVC split so the routing, the business rules and the data access stay in separate places, with REST endpoints behind JWT authentication for every operation.

Movie Recommendation System

Python, Streamlit, TF-IDF, TMDB API

Content-based recommendation over a catalogue of more than five thousand films. Each title becomes a vector of its own description and metadata, and a similarity search returns the neighbours — no ratings, no cold-start problem, just the film in front of you.

Posters and metadata come live from the TMDB API, and the whole thing runs on Streamlit Cloud so it can be opened from a link rather than cloned and installed.
